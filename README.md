# 🏀 Scoreboard

An interactive basketball-style scoreboard built using **HTML, CSS, and JavaScript**.

## 🚀 Features

- Add 1, 2, or 3 points to the Home score
- Add 1, 2, or 3 points to the Guest score
- Scores update instantly without refreshing the page
- Clean and simple user interface
- Responsive design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
